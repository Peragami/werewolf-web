役職もりもり人狼
― ONLINE WEREWOLF ―

友達とルームコードで集まって遊ぶオンライン人狼です。役職は各プレイヤーの端末にだけ表示されます。議論は対面や通話アプリでどうぞ。不足人数はBotで補充できます。
🐞 テスト用：ルームコードに DEBUG と打つと、役職の希望を設定できるデバッグルームに入れます。

ロビー
