# 役職もりもり人狼 Web版

ブラウザで遊べるオンライン人狼ゲームです。ルームコードで集まって、5〜12人（不足分はBot補充）で遊べます。

## 遊び方

GitHub Pagesで公開されているページを開き、名前を入れて「ルームを作る」か、友達のルームコードで「参加する」だけです。役職は各プレイヤーの端末にだけ表示されます。議論は対面や通話アプリでもできますが、Botは昼の議論でチャットに挨拶や自分の情報（占い・霊媒の結果など）から怪しい人を発言し、その発言に沿って投票します。

- 役職：人狼・第二人狼・狂人・狂信者・占い師・霊媒師・騎士・重騎士・シスター・大統領・妖狐・うらめしあ・アホ・のっとり・貧民・処刑人・村人（元リポジトリの「2D3D人狼作成指示書.docx」の仕様に準拠。霊媒師は「死んだ人の役職を確認する」仕様。保留枠のディーラー1／ディーラー2／狂神父／信者は未実装）
- 進行：夜（襲撃／占い／護衛／処刑など）→ 朝の結果発表 → 昼（議論）→ 投票 → 勝敗判定
- 同期：Firebase Realtime Database（HTTPS REST＋ポーリング）。ホストの端末が進行を管理します

## 構成

- `docs/` — Web版本体（GitHub Pagesの公開元）
  - `index.html` / `style.css` / `game.js`
- `original/` — 元リポジトリ（Peragami/werewolf）のファイル一式の保管庫。**中身は変更しないでください**

## 注意

身内で気軽に遊ぶための作りです。役職データはデータベース上に置かれるため、URLやコードを知る人が開発者ツール等で覗くと分かってしまう可能性があります。ガチ対戦用途ではありません。
